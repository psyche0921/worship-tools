로그인

주일 예배 기준으로 묶어서 보여 줘요. 찬양 제목으로 찾으면 그 주에 기획한 쇼츠도 함께 나와요.

검색된 이유

여기 나온 기록이 검색어와 맞았고, 목록에는 그 기록이 속한 주가 통째로 나와요.

작업 기록

서버에 Gemini API 키가 설정되지 않았어요. 쇼츠 기획을 하려면 서버 설정이 필요해요.

매주 월요일 오후 1시에 교회 유튜브 채널에서 그 주일 예배 영상을 찾아, 설교 구간 찾기부터 쇼츠 기획·설교 대본까지 만들어 작업 기록에 넣어 둬요. 영상이 아직 없으면 저녁 6시까지 30분마다 다시 봅니다.

지금까지 구글 드라이브에 모아 둔 악보를 서버로 옮기는 한시적인 기능이에요. 옮기고 나면 악보는 서버에 직접 올리니 이 카드는 없애집니다. 중간에 멈춰도 다시 누르면 남은 것부터 이어서 가져와요.

팀원은 세트리스트, 쇼츠 기획, 작업 기록을 사용할 수 있어요. Google Cloud의 OAuth 테스트 사용자에도 같은 이메일을 추가해야 할 수 있어요.
